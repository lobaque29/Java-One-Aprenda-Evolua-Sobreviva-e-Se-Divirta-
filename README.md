📚 Java One: Aprenda, Evolua, Sobreviva e Se Divirta!

    Do zero ao CRUD com Spring Boot 🚀

Este repositório contém o código-fonte, exercícios e projetos práticos baseados no livro Java One: Aprenda, Evolua, Sobreviva e Se Divirta (Programming One), escrito por Thiago Nogueira e publicado pela Editora Pensarbem[cite: 1].
🎯 Objetivo do Projeto

O objetivo principal deste repositório é guiar desenvolvedores na jornada do desenvolvimento Java, desde os conceitos fundamentais até a construção de aplicações backend modernas e completas utilizando o ecossistema Spring Boot[cite: 1].

A proposta segue a dinâmica Ideia ➔ Código ➔ Resultado[cite: 1]:

    Compreender a regra de negócio e escopo de uma aplicação real.

    Traduzir problemas do mundo real em código Java limpo e estruturado.

    Gerar resultados funcionais através de APIs REST e integrações com bancos de dados.

🧠 Conteúdo e Módulos

O repositório está estruturado cobrindo os seguintes pilares[cite: 1]:

    ☕ Java Fundamental

        Sintaxe, estruturas de controle, orientação a objetos e tratamento de exceções.

    🌱 Spring Boot

        Configuração de projetos, injeção de dependências e arquitetura em camadas.

    🔌 APIs RESTful

        Criação de controllers, mapeamento de rotas e manipulação de requisições HTTP (GET, POST, PUT, DELETE).

    💾 Banco de Dados & Persistência

        Mapeamento objeto-relacional (ORM) com Spring Data JPA, entidades e repositórios.

    🚀 Deploy & Produção

        Empacotamento da aplicação, variáveis de ambiente e boas práticas para publicação.

🛠️ Tecnologias e Ferramentas Utilizadas

    Linguagem: Java 17+[cite: 1]

    Framework Principal: Spring Boot 3+[cite: 1]

    Persistência: Spring Data JPA / Hibernate[cite: 1]

    Gerenciador de Dependências: Maven ou Gradle

    Banco de Dados: H2 Database (desenvolvimento) / PostgreSQL ou MySQL (produção)[cite: 1]

    IDE Recomendada: IntelliJ IDEA ou VS Code

⚙️ Como Executar o Projeto Localmente
PRÉ-REQUISITOS

    JDK 17 ou superior instalado

    Maven instalado (ou utilizar o wrapper ./mvnw)

    Git para clonar o repositório
